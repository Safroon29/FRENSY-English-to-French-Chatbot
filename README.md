# FRENSY – English to French Translation Chatbot

**FRENSY** is an AI-powered English-to-French translation chatbot developed using **Python** and **Hugging Face Transformers**. It uses a pre-trained neural machine translation model to convert English text into French while providing an interactive and user-friendly conversational experience.

Beyond basic translation, FRENSY integrates features such as **dynamic typing responses, translation history, French pronunciation support, vocabulary assistance, and basic conversational interactions**, making it both a translation tool and a simple language-learning assistant.

---

## Overview

Language translation is an important application of Natural Language Processing (NLP). FRENSY demonstrates how pre-trained transformer-based models can be integrated into an interactive chatbot to perform real-time English-to-French translation.

The project focuses on combining **AI-powered translation** with an engaging chatbot interface rather than building a machine translation model from scratch.

---

## Key Features

* **English-to-French Translation**
  Generates French translations from English input using a pre-trained Hugging Face translation model.

* **Interactive Chatbot Experience**
  Presents translations through a conversational interface.

* **Dynamic Typing Effect**
  Displays responses progressively to create a natural chatbot experience.

* **Translation History**
  Maintains previously generated translations for easy reference.

* **French Pronunciation Support**
  Helps users understand how translated French words and phrases are pronounced.

* **Vocabulary Assistance**
  Provides additional vocabulary support to encourage language learning.

* **Basic Conversational Responses**
  Handles common greetings and simple conversational inputs.
